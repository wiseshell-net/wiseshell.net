Este juego está hecho con C++ y SDL2, por lo que funciona en muchas plataformas: Windows, macOS, Linux, iOS y Android.

Los requisitos son muy bajos. El dispositivo debe tener una GPU para gráficos acelerados.

Si el dispositivo no tiene GPU, puedes probar el renderizado por software, pero no está soportado.

La versión estable actual es: **alpha**.
